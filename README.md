# Симулятор робота в комнатах

Веб-приложение для симуляции перемещения робота между комнатами с системой меток.

## Функциональность

- Плавное перемещение робота между комнатами
- Четкое разделение комнат с визуализацией соединений
- Система меток (ориентиры, цели, препятствия)
- Поиск пути между комнатами
- Обнаружение меток роботом
- Возможность расстановки и управления метками
